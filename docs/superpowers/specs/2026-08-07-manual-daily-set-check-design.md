# 手动今日训练组勾选与移除每日诺言诺语

## 目标

在 API 版训练录入弹窗中，为每个动作的每一组提供一个仅手动操作的“今日完成”圆圈；同时移除“每日诺言诺语”功能。

## 范围

### 今日训练组勾选

- 每个训练组行的左侧显示一个可点击圆圈。
- 圆圈默认空心；点击后显示勾选；再次点击取消勾选。
- 勾选仅表达当天是否手动打卡，不会由保存训练记录、重量或次数的变化自动修改。
- 状态的身份是“动作 ID + 该动作当前训练组序号”，不使用重量或次数作为身份的一部分。
- 当天内，状态必须在关闭并重新打开 App 后保留。
- 日期变化后，所有勾选自动视为未选；旧日期数据可保留在本地存储中，但不能显示为当天勾选。
- 新增的训练组默认未选；删除训练组时，该行的状态不再显示。后续组重新编号后，勾选随当前组序号处理。

### 移除每日诺言诺语

- 删除训练页的每日诺言诺语卡片、数据加载和样式。
- 删除设置页中每日诺言诺语的开关及相关页面逻辑。
- 删除不再使用的每日诺言诺语工具、数据或脚本测试；保留其他训练功能不变。

## 实现边界

- 使用现有的本地持久化模式，新增一个小而独立的今日勾选状态工具，方便对日期有效性和“动作 + 组序号”键进行单元测试。
- 训练页只负责在打开弹窗时读取状态、点击时切换状态；不把该状态写入训练记录表。
- 不改变既有训练记录、逐组重量/次数、动作排序、教程或部位标签的数据格式。

## 验收与测试

- 可验证状态键按动作和组序号隔离。
- 可验证首次默认未选、点击可选中、再次点击可取消。
- 可验证同一天重新读取仍保留，以及跨日读取为空。
- 训练页源码测试更新为不再依赖每日诺言诺语，并验证训练组行挂接可点击勾选。
- 现有数据测试套件继续通过。
