# API 版动作预览设计

日期：2026-07-30

## 目标

为 API 版 UniApp 增加独立的“动作预览”底部页面。用户可以按训练部位浏览动作，查看教程 GIF、动作名称和中文步骤，并按照动作库顺序左右滑动切换。

本次只修改 `app-api`，不修改 `app-local`。

## 用户交互

底部导航新增第三项：

- 训练记录
- 体重管理
- 动作预览

动作预览页面从上到下分为三层：

1. 页面标题和说明。
2. 横向滚动的部位标签：`全部、胸、肩、背、腿、有氧`，以及右侧 `+`。
3. 动作预览卡片：教程 GIF、动作中文名、部位、当前序号和中文动作步骤。

点击 `+` 时复用训练记录已有的自定义部位逻辑：

- 输入自定义显示名称；
- 选择一个动作部位或“全部”；
- 保存到同一个本地存储键；
- 训练记录和动作预览页面互相同步自定义标签。

左右滑动采用 `swiper`：

- 只在当前部位筛选结果中切换；
- 保持动作库原始顺序；
- 不循环，从第一个动作不能继续向左，从最后一项不能继续向右；
- 切换后同步更新 GIF、名称、部位、序号和步骤；
- 切换部位后回到该部位的第一个动作。

## 数据流

动作数据通过现有 `loadExerciseCatalog()` 加载，优先使用 API 版内置数据，目录缓存使用已升级的 v3 缓存键。

筛选规则复用 `trainParts.js`：

- “全部”返回完整动作目录；
- 默认部位使用既有聚合规则，例如“腿”包含股四头肌、小腿、臀部等；
- 自定义标签使用其关联的目标部位；
- 动作预览只读取目录，不读取训练数据库，也不会修改训练记录。

GIF 地址复用 `getExerciseGifSources()`，继续使用 API 版网络 GIF。加载失败时显示教程不可用占位内容，并保留中文步骤。

## 页面结构

新增 `pages/preview/index.vue`。

页面状态包括：

- `catalog`：完整动作目录；
- `activePart`：当前部位目标；
- `partTabs`：默认和自定义部位标签；
- `currentIndex`：当前动作在筛选结果中的索引；
- `imageFailed`：当前 GIF 是否加载失败；
- `loading`：动作目录加载状态。

新增 `pages/preview/index` 到 `pages.json`，并将其加入 tabBar。

动作预览页面可继续使用现有详情页的步骤拆分方式，将 `instructions_zh` 按中文和英文标点拆成步骤列表。

## 错误处理

- 动作目录加载失败：显示页面级提示，并保留下拉刷新或重新进入页面后的重试机会；
- 部位没有动作：显示空状态，不渲染空 swiper；
- GIF 加载失败：显示占位提示和动作步骤，不阻断左右切换；
- 自定义部位保存失败：沿用训练记录页面的提示方式，不切换当前标签。

## 测试和验收

新增页面测试应覆盖：

- 页面已注册并加入第三个底部标签；
- 页面包含部位标签、自定义部位入口和 swiper；
- 动作预览使用目录顺序；
- 切换部位后索引归零；
- 自定义部位仍使用现有存储键和关联规则。

完成后运行 API 版完整测试：

```
npm run test:data
```

验收标准：

- API 版底部出现“动作预览”；
- 默认部位标签与训练记录一致；
- 可新增自定义部位并关联全部或指定部位；
- GIF、动作名称和中文步骤同步切换；
- 左右滑动顺序稳定；
- 旧版训练记录、体重管理和动作库功能不受影响。

## 每日诺言诺语

训练记录页底部新增“每日诺言诺语”卡片，内容来自 API 版根目录的 `诺言诺语.txt)。

源文件每行一条，共 50 条。构建时将其整理为 API 版静态数据模块 `data/dailyQuotes.js`，运行时不读取外部文件，也不发起网络请求。显示时去除行首序号，保留原句内容。

训练记录页右上角增加设置入口，新增 `pages/settings/index.vue`：

- 设置项名称：每日诺言诺语；
- 默认开启；
- 关闭后训练记录页不显示每日卡片；
- 在设置页重新开启后恢复显示；
- 开关通过本地存储键 `fitness_daily_quote_enabled_v1` 持久化；
- 未保存过时按开启处理。

每日句子根据设备当前本地日期稳定计算索引，使用日期序号对 50 取余。同一天重复进入页面显示同一句，日期变化后自动切换，不依赖网络和时间接口。

每日卡片位于训练记录动作列表之后、页面底部导航之前。训练记录为空时仍显示每日卡片，只要开关处于开启状态。句子加载或解析异常时不阻断训练记录页面，隐藏卡片并记录可读的本地错误提示。

新增测试覆盖：

- `诺言诺语.txt` 解析为 50 条非空句子；
- 每日索引在同一天稳定，且始终落在 0 到 49；
- 默认开关为开启；
- 设置开关可以持久化关闭和重新开启；
- 训练记录页包含设置入口和每日卡片渲染条件；
- 设置页面已经注册，但不加入底部 tabBar。
